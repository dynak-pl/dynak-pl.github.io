# dynak.pl

Static one-page portal for the Dynak family: genealogy (webtrees), email, and hosting links.

Plain HTML/CSS/JS — no Bootstrap or jQuery.

## Deploy

Hosted on **GitHub Pages** from the `main` branch of this repo (`dynak-pl.github.io`).

Custom domain: **dynak.pl** (DNS at OVH — apex `A`/`AAAA` → GitHub Pages, `www` CNAME → `dynak-pl.github.io`).

Service subdomains such as `webtrees.dynak.pl` and `hosting.dynak.pl` still point at OVH hosting and are separate from this site.
